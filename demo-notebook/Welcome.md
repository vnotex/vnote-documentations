3. Enable side-by-side preview to see source and rendering together.

## About this notebook

This folder contains paired English and Chinese notes; `.zh.md` identifies the Chinese examples, not a VNote language pack. All links and content work offline.

To open your own copy, copy `demo-notebook` somewhere writable, then use the Notebooks panel menu → **Open Folder as Raw Notebook** (打开文件夹为原生笔记本) and choose that folder, not the repository root. Do not use **Open Notebook**, which expects a bundled notebook.

A raw notebook browses these files in place. Edits change the files on disk; copy the demo before experimenting. Tags, attachments, the recycle bin, encryption, and built-in notebook sync require a bundled notebook.
