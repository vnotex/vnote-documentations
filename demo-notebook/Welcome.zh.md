# 欢迎使用 VNote

这是一个用于探索 Markdown 的离线示例笔记本。所有内容均为虚构，无需账号、在线服务或个人笔记。

## 开始探索

- [Markdown 导览](<Markdown Tour.zh.md>)：标题、表格、任务清单和代码。
- [发布计划](<Projects/Release Plan.zh.md>)：位于子文件夹中的项目笔记。
- 使用右侧大纲在章节之间跳转。

## 体验写作流程

1. 从笔记本树打开 Markdown 导览。
2. 使用编辑器工具栏在编辑模式和阅读模式之间切换。
3. 开启并排预览，同时查看源码和渲染效果。

## 关于此笔记本

本文件夹包含成对的英文和中文笔记；`.zh.md` 用于标识中文示例，并非 VNote 语言包。所有链接和内容均可离线使用。

要打开自己的副本，请将 `demo-notebook` 复制到可写位置，然后在笔记本面板菜单中选择**打开文件夹为原生笔记本**，选择该文件夹而非仓库根目录。不要使用**打开笔记本**，该操作需要捆绑笔记本。

原始笔记本就地浏览这些文件。编辑会修改磁盘上的文件，因此请先复制示例再尝试。标签、附件、回收站、加密和内置笔记本同步需要捆绑笔记本。
