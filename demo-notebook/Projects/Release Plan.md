# Release Plan

A fictional release of a pocket field guide. This note shows how a folder groups a project without hiding the underlying files.

## Goal

Publish a short guide that a new reader can use offline.

## Milestones

| Milestone | Deliverable | Owner |
| --- | --- | --- |
| Draft | Three short chapters | Author |
| Review | Checked examples and links | Reviewer |
| Publish | A portable Markdown folder | Editor |

## Review checklist

- [x] Give each chapter a clear heading
- [ ] Check relative links
- [ ] Read the guide without a network connection

## Decision log

Keep the guide in plain Markdown so it is easy to inspect, back up, and share. Store related notes together and link to them rather than duplicating their content.
