# 发布计划

这是一份虚构的袖珍指南发布计划。本笔记展示如何用文件夹组织项目，同时保留清晰可见的文件结构。

## 目标

发布一份新读者可以离线使用的简明指南。

## 里程碑

| 里程碑 | 交付内容 | 负责人 |
| --- | --- | --- |
| 起草 | 三篇简短章节 | 作者 |
| 审阅 | 已检查的示例和链接 | 审阅者 |
| 发布 | 可携带的 Markdown 文件夹 | 编辑 |

## 审阅清单

- [x] 为每章设置清晰的标题
- [ ] 检查相对链接
- [ ] 断网阅读指南

## 决策记录

使用纯 Markdown 编写指南，方便查看、备份和分享。把相关笔记放在一起，通过链接引用，避免复制内容。
