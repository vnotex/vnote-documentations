# 仪表盘

打开 VNote 后，你会进入它的主界面。本页介绍你每天都会用到的区域，让文档的其余部分读起来更加顺畅。

## 主界面

VNote 的窗口分为三部分：两侧的停靠部件、中间的内容区，以及顶部的工具栏和菜单。

![VNote 主窗口：两侧是停靠部件，中间是内容区](../assets/screenshots/main.webp){ .screenshot }

## 笔记本面板

左侧的**笔记本**面板以树状结构显示你的**笔记本**、**文件夹**和**笔记**。用它来切换笔记本、展开任意层级的文件夹以及打开笔记。右键点击任意项即可进行创建、重命名、导入、导出等操作。面板标题栏菜单提供两种布局：**组合视图**在同一棵树中显示文件夹和笔记，**分离视图，双列**则把文件夹树和所选文件夹中的笔记并排显示。参见[笔记本、文件夹与笔记](../managing-notes/notebooks-folders-notes.md)。

![双列布局下的笔记本面板](../assets/screenshots/notes-two-columns.webp){ .screenshot loading=lazy }

## 内容区

中间区域是**内容区**，你在这里阅读和编辑笔记。VNote 以**标签页**的形式打开笔记，因此你可以同时保留多篇笔记并在它们之间切换。标签页可以拆分为多个并排视图，方便对比笔记或一边写作一边参考另一篇。

## 停靠部件

内容区周围是停靠部件。它们可以自由拖放，停靠到窗口的左、上、右或下方。最常用的有：

- **笔记本**——上文所述的笔记本/文件夹/笔记树。
- **大纲**——当前笔记的可交互标题结构；点击标题即可跳转。
- **搜索**——跨笔记本的全文与名称搜索；参见[搜索面板](../search/search-panel.md)。
- **标签**——按[标签](../managing-notes/tags.md)浏览和筛选笔记。
- **历史**——最近打开的笔记；参见[快速访问与历史](../managing-notes/quick-access-history.md)。
- **片段**——插入可复用文本；参见[片段](../editing/snippets.md)。
- **评论（Comments）**——用于 [PDF 阅读器](../managing-notes/pdf-viewer.md)等支持评论的视图；不支持时会隐藏。
- **工具（Tools）**——承载当前视图提供的工具，例如[思维导图节点属性](../editing/mind-maps.md)。标题随当前工具面板变化；当前视图不提供面板时不可用。

通过**视图 → 窗口列表（Windows List）**显示或隐藏可用的停靠面板。重新排列后，可用**设置 → 重置主窗口布局（Reset Main Window Layout）**恢复布局。

## 便签（Stickers）

主页标签页本身由**便签**组成——它们是排布在网格上的小面板。全新配置默认包含**问候（Greeting）**、**日历（Calendar）**、**活动（Activity）**和**历史（History）**。使用**添加便签（Add Sticker）**可以添加更多，**重置仪表盘（Reset Dashboard）**可恢复默认布局；便签标题栏上有**移除（Remove）**按钮。

面板默认处于**锁定**状态，以免误拖打乱布局。选择**解锁仪表盘（Unlock Dashboard）**即可重新排布：

- 拖动便签中央可移动它，拖动边缘或角可调整大小。
- 使用键盘时，按 `Tab` 聚焦便签，然后用方向键移动、用 `Shift` 加方向键调整大小——每按一次移动或改变一个网格单元。
- 面板解锁时，点击作用于布局而非便签内容。拖到面板之外会被拉回边界内，拖到已被占用的区域会被拒绝，按 `Esc` 或右键点击可取消拖动。

完成后记得重新锁定面板。移动与调整大小都在面板上直接完成：原先标题栏中的**移动**子菜单和**调整大小…**对话框已被移除，标题栏只保留**移除（Remove）**。

### 问候与使用提示

**问候**便签通常显示与当前时段对应的问候语，每小时的前五分钟则改为显示使用提示。此外，VNote 可在启动时显示每日一次的 **VNote 提示（VNote Tip）**通知：选择**确定（OK）**将其关闭，或选择**不再显示（Never show again）**停用后续每日提示。提示语言跟随界面语言偏好，而非日期、数字的地区格式。

## 通知

工具栏中的通知按钮会在有需要你留意的事情时显示角标。点击它会打开通知中心，这是一个最新在前的列表，条目可以提供**详情（Details）**或各自的操作，**全部清除（Clear All）**可清空列表。重要消息还会以浮层提示出现在窗口之上——若主窗口已隐藏，则显示为托盘气泡。上文的每日提示停用选项不会禁用其他通知。

## 工具栏与菜单

窗口顶部提供常用操作的快捷入口——新建笔记、导入、导出、[快速访问](../managing-notes/quick-access-history.md)、[任务](../productivity/tasks.md)、[统一入口](../search/united-entry.md)、[设置](../customization/settings.md)等。**新建 → 快速笔记**让你在还没决定归属之前就能立即记下想法——参见[快速笔记](../productivity/quick-note.md)。

纯文字的**视图**菜单包含窗口、布局控制以及**窗口列表**。纯文字的**设置**菜单包含**设置**、**主题**、**打开配置文件夹**，以及 **Markdown 指南（Markdown Guide）**、**快捷键帮助（Shortcuts Help）**等帮助入口。其中的**全部锁定（Lock All）**操作参见[加密笔记](../managing-notes/encrypted-notes.md)。

## 以命令驱动的导航

除了点击，VNote 更是为键盘而生。按下[统一入口](../search/united-entry.md)快捷键，即可用简短命令搜索并跳转到任意位置；并可借助[键盘快捷键](../customization/keyboard-shortcuts.md)——包括完整的 [Vi 模式](../editing/vi-mode.md)——让双手不离主键位地工作。
