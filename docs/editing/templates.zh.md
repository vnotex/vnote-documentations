# 模板

**模板**是新建笔记的起点。你不必每次都面对一个空白文件，而是可以创建一篇已经包含你惯用结构的笔记——标题、front matter、标准小节——并自动填好。

## 使用模板

创建笔记时，**新建笔记**对话框允许你选择一个模板。新笔记会以该模板的内容创建，而不是空白正文。

## 模板存放位置

VNote 把模板文件存放在其配置中的 `templates` 文件夹里。**一个文件就是一个模板。** 你可以用系统的文件浏览器直接在该文件夹中添加或删除模板——无需任何特殊的导入步骤。配置文件夹的位置参见[设置](../customization/settings.md)。

## 模板中的片段

模板支持[片段](snippets.md)，这正是让它们变得动态的关键。模板可以调用片段，在创建笔记时自动填入内容。

例如，下面这个模板使用内置的 `%no%` 片段，它会求值为笔记名（不含后缀）：

```md
# %no%
这是一个使用片段自动把笔记名作为标题插入的模板。
```

如果你创建一篇名为 `week report.md` 的笔记，新笔记会变成：

```md
# week report
这是一个使用片段自动把笔记名作为标题插入的模板。
```

任何片段都可以在此使用，因此模板可以插入当前日期、搭建代码块骨架、定位光标等等。把模板与片段结合，就能让新笔记一创建便可立即动笔。
