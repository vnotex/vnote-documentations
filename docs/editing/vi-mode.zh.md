# Vi 模式

VNote 源自受 Vim 启发的工作流，并提供内置的 **Vi 模式**，用于模式化、以键盘驱动的编辑。如果你习惯以移动（motion）和操作符（operator）来思考，Vi 模式能让你编辑笔记时双手无需离开主键位。

## 启用 Vi 模式

在[设置](../customization/settings.md)中开启 Vi 模式。启用后，编辑器以**普通模式**启动，惯常的模式化编辑会作用于你的所有笔记。

## 各种模式

Vi 模式带来了模式化编辑器中熟悉的状态：

- **普通（Normal）**——按键即命令。移动和操作文本，而不插入内容。
- **插入（Insert）**——照常输入文本。用 `i`、`a`、`o` 等进入，用 `Esc` 退出。
- **可视（Visual）**——通过移动选择文本，然后对选区进行操作。
- **命令行（Command-line）**——用 `:` 命令执行面向行的操作。

## 支持哪些功能

Vi 模式实现了你最常用的移动与操作符：

- **移动**——`h j k l`、`w b e`、`0 ^ $`、`gg G`、段落与搜索移动，以及像 `3w` 这样的计数。
- **操作符**——`d`（删除）、`c`（更改）、`y`（复制），与移动和文本对象组合（`diw`、`ci"`、`dd`、`yy`）。
- **编辑**——`x`、`r`、`p`/`P`、`u`（撤销）与重做、`.` 重复。
- **搜索**——`/` 与 `?` 搜索，`n`/`N` 重复。
- **寄存器与标记**，用于复制与跳转。

它旨在覆盖日常编辑，而非 Vim 的每一个角落；高度专门化的插件和 Ex 功能不在其范围之内。

## Vi 模式与 VNote 快捷键

Vi 模式管辖笔记内部的文本编辑。VNote 的应用级操作——切换笔记、打开面板、[统一入口](../search/united-entry.md)、[片段](snippets.md)——仍使用它们自己的[键盘快捷键](../customization/keyboard-shortcuts.md)，其中许多本身就是组合键（例如 `Ctrl+G, I`）。二者协同工作：Vi 用于编辑，VNote 快捷键用于在应用中导航。

## 如果你不用 Vi

Vi 模式完全可选，未启用时默认关闭。禁用后，编辑器的行为与常规文本编辑器相同。无论哪种方式，都可参见[键盘快捷键](../customization/keyboard-shortcuts.md)来自定义你操控 VNote 的方式。
