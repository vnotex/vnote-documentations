# 加密笔记

VNote 可以在可写的**捆绑笔记本**中，对单篇 **Markdown**、**纯文本**和**思维导图**笔记的**正文**进行加密。原始笔记本不支持此功能。加密笔记使用由密码保护、可随笔记本迁移的密钥层级；同一笔记本中的普通笔记仍不加密。

!!! warning "正文加密不等于整个笔记本加密"
    文件名、文件夹名、标签和其他笔记本元数据仍然可见。作为独立文件保存的图片、附件，以及评论附属文件，仍然**不加密**。加密不会清除 Git 历史、云端历史版本、备份、共享资源或外部源文件中已有的明文，也不等同于安全删除。

## 新建或加密笔记

- 新建笔记时，在**新建笔记（New Note）**中选择受支持的类型，并勾选**加密笔记（Encrypt note）**。
- 对已有笔记，在笔记本浏览器中选中它们，从右键菜单选择**加密（Encrypt）**。每次选择同一个笔记本中的笔记，阅读警告后确认**加密**。VNote 会就地转换所选笔记的正文，不会扫描或改写其独立资源文件。

首次使用时，VNote 会准备笔记本的加密密钥：

1. 如果没有可提供主密码的已初始化笔记本，**设置笔记加密（Set Up Note Encryption）**会要求填写**主密码（Master password）**和**确认密码（Confirm password）**。输入一致的密码后，选择**设置加密（Set Up Encryption）**。
2. 如果另一个已打开的捆绑笔记本已经初始化加密，VNote 会使用该笔记本的主密码层级，并在需要时要求解锁它。如果有多个不同的密钥层级可用，**选择主密码（Choose Master Password）**会让你选择来源笔记本。
3. 当前笔记本初始化之后，后续操作会解锁其现有密钥，而不是重新创建密钥。

!!! danger "妥善保管主密码"
    忘记主密码后，无法通过重置密码恢复加密内容。请妥善保管密码，并备份包含密钥在内的完整笔记本。同步密码或个人访问令牌不能解锁加密笔记。

### 旧笔记本与首次设置

旧笔记本可能没有记录加密初始化状态。如果 `vx_notebook/encryption.vne` 不存在，且无法确定以前是否使用过加密，VNote 会在设置前要求明确确认。**只有该笔记本从未使用过加密时，才能继续。** 取消此确认不会改变笔记或配置。

如果以前使用过加密，请取消，并从完整、一致的备份中恢复原始密钥数据。新生成的密钥无法恢复使用已丢失密钥加密的笔记。参见[备份与恢复](#backup-and-recovery)。

## 解锁与锁定

在 VNote 中打开加密笔记，并在提示时输入主密码。解锁会让受保护正文可供 VNote 编辑器使用，不会把磁盘上的笔记变成普通明文文件。不支持使用外部应用打开受保护笔记。

使用**设置菜单 → 全部锁定（Lock All）**，可以保存受保护笔记的改动并关闭其视图，同时保留普通笔记标签页。如果保存或锁定报错，请先解决问题，不要直接认为笔记本已经锁定。

## 就地解密

在笔记本浏览器中选中加密笔记并选择**解密（Decrypt）**。按提示解锁，阅读警告后确认**解密**，即可将它们就地转换为普通笔记。这是格式转换，而不是导出或创建另一份明文副本。

此后，笔记正文及其中嵌入的 Base64 图片将以**未加密**形式保存，后续同步或备份也可能包含这些明文。独立图片、附件和评论保持不变；解密也不会清除已有历史或备份。

## 图片、预览、搜索与导出

- **嵌入图片：** Base64 是加密 Markdown 笔记默认的图片插入方式。Base64 是编码，不是加密：只有将图片字节保存在加密正文中，它们才受保护。此前通过链接引用的图片文件不会自动嵌入或加密。插入方式参见[图片与图床](../editing/images-and-image-host.md)。
- **独立资源：** 附件的**打开（Open）**、**打开文件夹（Open Folder）**和**复制路径（Copy Path）**等操作，仍针对普通的未加密文件。不要把敏感内容放在独立附件或评论中，并期待正文加密能保护它们。
- **预览与数学公式：** 受保护预览使用仅驻留内存的配置。内置 KaTeX 可以在加密 Markdown 的阅读模式和实时预览中离线使用；编辑器内的原地数学公式预览仍不可用。参见[数学公式与图表](../editing/math-and-diagrams.md)。
- **搜索：** 普通的跨笔记内容搜索会跳过加密正文，**即使笔记已经解锁也不例外**。搜索可以报告跳过的加密文件数量；仍可通过可见的名称、文件夹和标签查找笔记。解锁不会使正文参与全局搜索或替换。参见[搜索面板](../search/search-panel.md)。
- **导出与打印：** 不支持导出或打印加密笔记正文。普通笔记的操作参见[导出](../productivity/export.md)；先解密再处理意味着主动移除正文的加密保护。

## 备份与恢复 { #backup-and-recovery }

复制或同步**整个笔记本**，包括其配置和完整密钥层级，并保留主密码。单个加密笔记文件不足以构成备份。如果使用自定义的外部资源或回收站路径，还需要按[笔记本同步](notebook-sync.md)中的说明单独备份这些内容。

如果 VNote 提示已知的加密密钥丢失或需要恢复，请保留当前笔记本和备份，并从一致的备份中恢复原始 `vx_notebook/encryption.vne` 及配套笔记本数据。**不要删除密钥文件，不要用新生成的密钥替换原始密钥，也不要混合不同版本的加密文件和密钥。** 如果转换或新建报错要求在编辑或同步前重启，请先按提示重启再继续；错误持续时，应保留恢复数据。

迁移部分笔记时，请使用 VNote 的[跨笔记本复制与移动](notebooks-folders-notes.md#copy-and-move-between-notebooks)或[分享文件夹导入](importing-migrating.md#import-a-shared-folder)，而不是手动复制孤立的加密文件。导入加密分享文件夹需要来源主密码，以及已初始化并解锁的目标笔记本；完整步骤见导入指南。
