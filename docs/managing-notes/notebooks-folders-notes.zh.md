# 笔记本、文件夹与笔记

VNote 用一套简单、透明的层级来管理你的写作：**笔记本**、**文件夹**和**笔记**。这套结构直接对应你的文件系统，因此你在 VNote 中看到的，正是磁盘上真实存在的。

## 层级结构

- **笔记本**是一个自包含的容器。在磁盘上它是一个称为**笔记本根文件夹**的目录，保存着该笔记本的所有笔记与配置。
- **文件夹**用于在笔记本内将相关笔记归为一组。它对应笔记本根文件夹内的一个目录，并且文件夹可以嵌套到**无限层级**。
- **笔记**是文件夹内的单个文件——通常是 Markdown（`.md`）文件，但 VNote 也能打开和编辑其他文本文件。

VNote 会在每个笔记本内保存少量索引文件以跟踪其笔记。因此，最好**在 VNote 内**创建、移动和重命名笔记，而不要绕过它直接改动目录结构。

## 笔记本

笔记本是独立且自解释的：它所需的一切都位于其根文件夹之下。正因如此，你才能把一个笔记本当作单个目录来复制、同步或做版本管理。

### 创建笔记本

- **从空文件夹创建**——选择**新建笔记本**并让 VNote 指向一个空目录。这是最常见的起点。
- **从现有文件夹创建**——如果你已经有一个装满 Markdown 文件的目录，选择**从文件夹新建笔记本**即可围绕它们构建笔记本，而无需移动任何文件。参见[导入与迁移](importing-migrating.md)。

### 打开与关闭笔记本

你创建或导入的笔记本会出现在左侧的笔记本选择器中。关闭笔记本只会将其从 VNote 的列表中移除；磁盘上的文件不受影响，你随时可以再次导入。

## 文件夹

在导航面板中右键点击笔记本或现有文件夹，即可创建**新建文件夹**。由于嵌套没有层级限制，你既可以用扁平的笔记列表，也可以构建深层、结构化的知识库。文件夹可以从同一个右键菜单进行重命名、移动和删除。

## 笔记

选中笔记本或文件夹并选择**新建笔记**即可创建笔记。为其命名时加上 `.md` 后缀以创建 Markdown 笔记。从笔记的右键菜单中，你可以重命名、移动（在文件夹间剪切与粘贴）、复制、删除和导出笔记，还能在系统文件管理器中显示对应文件。

删除笔记会将其移入笔记本内 VNote 的回收站，因此在你清空之前都可以恢复。

## 一切皆文件

由于该层级不过是目录和文本文件，你始终完全掌控自己的数据：

- 复制笔记本的文件夹即可备份。
- 用 git 跟踪笔记本的历史。
- 需要时用其他工具编辑某篇笔记。

为保持 VNote 索引的一致性，建议在 VNote 内进行结构性改动（创建、移动、重命名、删除）。跨设备同步参见[笔记本同步](notebook-sync.md)，跨文件夹树组织笔记参见[标签](tags.md)。
