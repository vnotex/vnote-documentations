# PDF 阅读器

VNote 使用内置阅读器（内置的 pdf.js 3.11.174）打开 `.pdf` 文件，因此笔记本中的 PDF——论文、手册、扫描讲义——都可以在不离开应用的情况下与笔记对照阅读。PDF 仅供查看：VNote 绝不会修改它们，你也无法新建 PDF 笔记（参见[文件类型](file-types.md)）。

![在 VNote 内置查看器中打开的 PDF](../assets/screenshots/pdf.webp){ .screenshot loading=lazy }

## 阅读 PDF

打开 PDF 的方式与打开其他笔记完全相同——从笔记本浏览器、从[快速访问与历史](quick-access-history.md)，或者把文件拖入内容区。阅读器提供常用控件：翻页、缩放、旋转，以及全文搜索。

由于 PDF 是在普通视图窗口中打开的，你熟悉的标签页操作同样适用：可以拆分内容区，让 PDF 与正在撰写的笔记并排显示，也可以把它分离成独立窗口。参见[编辑器基础](../editing/editor-basics.md)。

阅读器自带的导航面板（缩略图与书签）在文档打开时默认隐藏，好让页面本身占据全部宽度。需要时可从阅读器工具栏切换显示。

## 大纲与书签

如果 PDF 内嵌了大纲（书签），VNote 会读取它并提供两种导航方式：

- **大纲**停靠部件会像显示 Markdown 笔记的标题结构一样显示 PDF 的大纲。点击条目即可跳转到对应页面。
- 每个视图窗口的工具栏中都有一个**大纲**弹出框，这对看不到停靠部件的分离窗口或分屏窗口尤其方便。

超大的大纲会在 5000 个条目处截断；文档本身仍可完整阅读。

## 限制

批注、填写表单与编辑不在支持范围内——这些请使用专门的 PDF 应用。若要把自己的笔记转成 PDF，参见[导出](../productivity/export.md)。

!!! warning "该行为因操作系统而异"
    内置阅读器需要 Qt 6 构建版本（Windows、Linux 和 macOS）。在基于 Qt 5.15 构建的 `win64-windows7` 安装包中，打开 PDF 只会看到**空白的阅读器**：其 Chromium 83 引擎无法解析内置的 pdf.js。这是该安装包的已知限制。请在那里使用外部阅读器打开 PDF——或者在**设置 → 文件关联 → 外部程序**中把 `.pdf` 关联到系统的 PDF 应用。
