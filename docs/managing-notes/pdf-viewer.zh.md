# PDF 阅读器

VNote 使用基于 pdf.js 6.2.108 的内置阅读器打开 `.pdf` 文件，因此笔记本中的 PDF——论文、手册、扫描讲义——都可以在不离开应用的情况下与笔记对照阅读和批注。PDF 文件本身仍为只读：批注单独保存，你也无法新建 PDF 笔记（参见[文件类型](file-types.md)）。

![在 VNote 内置查看器中打开的 PDF](../assets/screenshots/pdf.webp){ .screenshot loading=lazy }

## 阅读 PDF

打开 PDF 的方式与打开其他笔记完全相同——从笔记本浏览器、从[快速访问与历史](quick-access-history.md)，或者把文件拖入内容区。原生工具栏提供翻页、缩放、旋转、文本选择、抓手滚动、滚动与跨页模式、文档属性、演示模式和文本搜索；较少使用的控件集中在**更多（More）**菜单中。

由于 PDF 是在普通视图窗口中打开的，你熟悉的标签页操作同样适用：可以拆分内容区，让 PDF 与正在撰写的笔记并排显示，也可以把它分离成独立窗口。参见[编辑器基础](../editing/editor-basics.md)。

阅读器的导航面板包含缩略图、书签、附件和图层。文档打开时它默认隐藏，好让页面本身占据全部宽度；需要时可使用工具栏中的**切换侧栏（Toggle Sidebar）**。

## 大纲与书签

如果 PDF 内嵌了大纲（书签），VNote 会读取它并提供两种导航方式：

- **大纲**停靠部件会像显示 Markdown 笔记的标题结构一样显示 PDF 的大纲。点击条目即可跳转到对应页面。
- 每个视图窗口的工具栏中都有一个**大纲**弹出框，这对看不到停靠部件的分离窗口或分屏窗口尤其方便。

超大的大纲会在 5000 个条目处截断；文档本身仍可完整阅读。

## 批注与标记

PDF 工具栏提供三种批注工具。点击工具按钮主体可启用或停用该工具；同一按钮上的下拉菜单用于配置它：

- **高亮（Highlight）**——拖过文本即可高亮，或者先选中文本，再从页面右键菜单中选择**高亮（Highlight）**。其菜单用于设置颜色。
- **绘制（Draw）**——在页面上拖动以添加手写线条。其菜单用于设置颜色、线条粗细和不透明度。
- **文本框（Text box）**——点击以放置文本框并直接输入。按 `Ctrl+Enter` 或点击别处完成输入；双击已有文本框可编辑，拖动文本框可移动。其菜单用于设置颜色和字号。

打开**批注（Comments）**停靠部件即可按页浏览批注。选择条目会跳转到对应位置；下方窗格可用于添加或编辑备注、更改颜色或删除批注。批注改动会自动保存，绝不会把 PDF 本身标记为已修改。

批注按文件保存。捆绑笔记本会把 `comments.json` 放在该文件的附件文件夹中，因此它会随笔记本迁移，并参与内置同步。原始笔记本或外部 PDF 会使用相邻的 `<文件名>.pdf.comments.json` 文件。VNote 重命名、移动或删除 PDF 时，也会一并处理这个伴随文件。

## 限制

PDF 本身仍为只读；填写表单与修改文档内容仍需使用专门的 PDF 应用。若要把自己的笔记转成 PDF，参见[导出](../productivity/export.md)。

!!! warning "内置阅读器需要 Qt 6.9 或更高版本"
    当前常规 Windows、Linux 和 macOS 安装包均满足此要求。`win64-windows7` 安装包使用 Qt 5.15，因此 VNote 不会在其中创建内置 PDF 标签页；它会打开已配置的外部 PDF 应用，未配置时则使用系统默认应用。你可以在**设置 → 文件关联 → 外部程序**中选择应用。
