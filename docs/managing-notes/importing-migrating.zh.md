# 导入与迁移

由于 VNote 笔记本只是一个装着纯文件的目录，把已有笔记导入 VNote，或在电脑之间迁移 VNote 笔记本，都非常简单。本页讲解如何把内容导入进来；跨设备保持笔记本同步请参见[笔记本同步](notebook-sync.md)。

## 从现有文件夹构建笔记本

推荐的做法是把你的文件导入一个**捆绑笔记本**，让它们获得笔记本索引所提供的一切——[标签](tags.md)、附件、回收站以及内置的 [Git 同步](notebook-sync.md)：

1. 选择**新建笔记本**，保持**类型**为**捆绑笔记本（Bundled notebook）**，并让它指向一个空文件夹（捆绑笔记本的根文件夹必须为空）。
2. 选中该笔记本或其中的某个文件夹，然后从工具栏的**新建**菜单中选择**导入文件夹（Import Folder）**，并选取你已有的目录。你的文件会作为文件夹和笔记被复制进来。

你也可以从 VNote 之外直接把文件复制到笔记本根文件夹中。它们随后会显示为[外部文件](notebooks-folders-notes.md#the-index-and-external-files)，你可以用**导入到索引（Import to Index）**将其纳入——或者只要启用了**打开时导入外部文件（Import External Files on Open）**，VNote 会在你第一次打开时替你纳入。对于层级较深的目录树，**导入文件夹**更省事，因为纳入外部文件夹每次只能处理一层。

### 什么时候更适合用原始笔记本

当文件夹应当按其现状被接纳时，选择**类型 → 原始笔记本（Raw notebook）**并让 VNote 指向你的目录：

- 不会导入或重新整理任何内容，也不会在文件夹中写入任何 VNote 配置文件——VNote 就地浏览它，很像文件浏览器。
- 当文件夹的结构由 VNote 之外的东西维护——另一个工具、一段脚本或一个共享仓库——并且该布局应当保持权威时，这就是正确的选择。

原始笔记本并非只读：新建、重命名、移动、导入笔记以及粘贴图片，都会照常写入该文件夹。它避免的是对已有内容的一次性迁移。

代价是原始笔记本没有索引，因此标签、附件、回收站以及内置的 Git 同步都不可用。完整对比参见[笔记本、文件夹与笔记](notebooks-folders-notes.md#which-type-should-i-use)。

## 导入现有笔记本

捆绑笔记本是一个自包含的目录，因此导入笔记本只需让 VNote 指向它的根目录：

1. 选择**打开笔记本（Open Notebook）**，并选择它的**笔记本根文件夹**。
2. VNote 读取该笔记本的配置文件并将其还原——文件夹、笔记和设置都会一如从前地重新出现。

在另一台机器上创建的笔记本，或从备份中恢复的笔记本，都是这样接入的。原始笔记本的文件夹中没有配置，因此接入它的方式与创建时相同：使用**新建笔记本**并将**类型**设为**原始笔记本（Raw notebook）**，指向该目录即可。

## 将文件和文件夹导入笔记本

你可以在 VNote 内把外部内容导入现有笔记本。在笔记本面板中选中目标笔记本或文件夹，然后使用工具栏的**新建**菜单：

- **导入文件（Import Files）**——将单个外部文件作为笔记复制进来。
- **导入文件夹（Import Folder）**——将整个外部目录树递归地复制进来（会跳过隐藏项）。

导入的项目会放在笔记本中所选位置之下。

## 将笔记本迁移到另一台电脑

由于捆绑笔记本所需的一切都位于其根文件夹之下，迁移就是一次复制：

1. 将笔记本根文件夹复制到另一台机器（通过 U 盘、同步文件夹或 git）。
2. 在另一台机器上，把该文件夹**打开**为笔记本。

原始笔记本只携带你的文件。复制该文件夹能把内容带过去，但另一台机器会把它作为一个新的原始笔记本打开，并为它建立自己的本地记录。

一种常见做法是把笔记本根文件夹放在由第三方服务同步的目录中——例如 Dropbox 或 OneDrive——并在每台电脑上打开它。这样你在 VNote 中编辑和管理笔记，而文件由你早已信任的服务同步。更多细节以及 VNote 内置的 Git 同步，参见[笔记本同步](notebook-sync.md)。

## 从其他应用迁移

VNote 没有内置针对其他笔记应用的导入器，但由于它处理纯 Markdown 与图片，通常只要从其他工具导出为 Markdown，就足以把内容迁移过来。从特定工具迁移的建议参见[数据迁移](../help/data-migration.md)。
