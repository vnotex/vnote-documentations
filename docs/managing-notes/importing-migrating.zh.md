# 导入与迁移

由于 VNote 笔记本只是一个装着纯文件的目录，把已有笔记导入 VNote，或在电脑之间迁移 VNote 笔记本，都非常简单。本页讲解如何把内容导入进来；跨设备保持笔记本同步请参见[笔记本同步](notebook-sync.md)。

## 从现有文件夹构建笔记本

如果你已经有一个装着 Markdown 文件的目录，无需复制或重新整理任何东西。选择**从文件夹新建笔记本**并让 VNote 指向该目录。VNote 会把它当作笔记本根文件夹，并围绕其中已有的文件建立索引。

对于已有的笔记集合，这是开始使用 VNote 的推荐方式。

## 导入现有笔记本

笔记本是一个自包含的目录，因此导入笔记本只需让 VNote 指向它的根目录：

1. 选择导入笔记本，并选择它的**笔记本根文件夹**。
2. VNote 读取该笔记本的配置文件并将其还原——文件夹、笔记和设置都会一如从前地重新出现。

在另一台机器上创建的笔记本，或从备份中恢复的笔记本，都是这样接入的。

## 将文件和文件夹导入笔记本

你可以在 VNote 内把外部内容导入现有笔记本。从笔记本或文件夹的右键菜单中导入：

- **文件**——将单个外部文件作为笔记复制进来。
- **文件夹**——将整个外部目录树复制进来。

导入的项目会放在笔记本中所选位置之下。

## 将笔记本迁移到另一台电脑

由于笔记本所需的一切都位于其根文件夹之下，迁移就是一次复制：

1. 将笔记本根文件夹复制到另一台机器（通过 U 盘、同步文件夹或 git）。
2. 在另一台机器上，把该文件夹**导入**为笔记本。

一种常见做法是把笔记本根文件夹放在由第三方服务同步的目录中——例如 Dropbox 或 OneDrive——并在每台电脑上导入它。这样你在 VNote 中编辑和管理笔记，而文件由你早已信任的服务同步。详情以及如何使用 git，参见[笔记本同步](notebook-sync.md)。

## 从其他应用迁移

VNote 没有内置针对其他笔记应用的导入器，但由于它处理纯 Markdown 与图片，通常只要从其他工具导出为 Markdown，就足以把内容迁移过来。

社区工具可以帮助清理。例如 [ImageBedMoving](https://github.com/StarLeet/ImageBedMoving) 会把散落在各文件夹中被引用的图片汇集到 VNote 的 `vx_images` 文件夹——在从外部文件夹构建笔记本之后尤其好用。当前的辅助工具清单参见[数据迁移](../help/data-migration.md)。
