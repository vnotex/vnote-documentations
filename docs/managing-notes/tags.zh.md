# 标签

文件夹按位置组织笔记——一篇笔记只存在于一个文件夹中。**标签**则按主题组织笔记，而且一篇笔记可以携带任意多个标签。二者结合，让你既能保持整洁的文件夹树，又能把散落各处的相关笔记归拢在一起。

!!! note "标签需要捆绑笔记本"
    标签保存在笔记本的索引中，而只有[捆绑笔记本](notebooks-folders-notes.md#which-type-should-i-use)才有索引。在原始笔记本中，**标签（Tags）**按钮不会显示，标签弹出框会提示该类型的笔记本不支持标签。

## 标签的用途

当单个文件夹无法体现你对一篇笔记的理解方式时，就用标签。一篇会议记录可以打上 `project-x` 和 `2026-q1` 标签；一篇代码片段笔记可以打上 `python` 和 `reference` 标签。之后，无论笔记位于文件夹树的哪个位置，你都能调出带有某个标签的所有笔记。

标签保存在笔记本的配置中，因此当你复制或[同步](notebook-sync.md)笔记本时，标签会随之一起迁移。

## 添加与移除标签

打开一篇笔记，使用笔记工具栏中的**标签（Tags）**按钮，在标签弹出框中添加一个或多个标签。输入新的标签名即可创建，或从你已使用的标签中选择。用同样的方式从笔记上移除标签。笔记的工作方式与之前完全一致——打标签不会改变 Markdown 文件的任何内容。

## 按标签浏览笔记

**标签**停靠部件列出当前笔记本中的所有标签。选择某个标签即可看到携带它的每一篇笔记，然后直接从列表中打开笔记。这会把一组散乱的笔记变成聚焦于主题的视图。

![列出笔记本中所有标签的标签停靠部件](../assets/screenshots/tags.webp){ .screenshot loading=lazy }

## 用统一入口按标签查找

[统一入口](../search/united-entry.md)可以按标签搜索，因此你无需打开停靠部件，就能用键盘跳转到带标签的笔记。使用 `find` 命令，配合标签对象与作用域：

- `find -b tag -s notebook`——在当前笔记本中按标签搜索。
- `find -b tag -s folder`——在当前文件夹中按标签搜索。
- `find -b tag -s all_notebook`——在所有笔记本中按标签搜索。

输入命令，再输入标签关键词，即可即时筛选。

## 小贴士

- 保持一套小而一致的标签词汇——少量精选的标签比大量一次性标签更有用。
- 将标签与[快速访问与历史](quick-access-history.md)和[搜索](../search/index.md)结合，在相关笔记间快速穿梭。
