# 笔记本同步

笔记本是一个文件目录，可以在多台机器之间同步。捆绑笔记本支持内置的 **Git**、**WebDAV**（包括 Nextcloud）和**坚果云（WebDAV）**同步；捆绑笔记本和原始笔记本也都可以使用文件夹同步服务。普通笔记仍是可直接读取的文件，而[加密笔记](encrypted-notes.md)需要通过 VNote，使用对应密钥和主密码打开。

## 选择同步方式

| 方式 | 远端存储 | 身份验证 |
| --- | --- | --- |
| Git | 普通 Git 仓库 | 个人访问令牌（PAT）；按需填写 Git 用户名 |
| WebDAV / Nextcloud | 专用的现有集合中的普通笔记本文件 | 用户名和密码或应用密码 |
| 坚果云（WebDAV） | VNote 管理的版本化存储，不供云端直接编辑笔记 | 坚果云用户名和应用密码 |
| 文件夹同步服务 | 本地文件夹的同步副本 | 由同步客户端管理 |

## 配置内置同步

新建**捆绑笔记本**时，在**新建笔记本**中选择**同步方式（Sync method）**，然后在创建前点击**配置（Configure）**。对于现有笔记本，使用笔记本面板的**同步信息（Sync Info）**配置同步。**管理笔记本（Manage Notebooks）**会以只读文本显示当前方式。原始笔记本不支持内置同步。

### 内置 Git 同步

VNote 会在应用内处理克隆、提交、拉取和推送。请先创建远端仓库；新建笔记本时，应先在 Git 托管服务上创建一个空仓库。填写：

- **远端 URL（Remote URL）**——HTTPS Git 地址（例如 `https://github.com/user/repo.git`），或 `file://` URL，例如 `file:///path/to/repo.git`。
- **Git 用户名（Git user name）**——PAT 所有者的登录名，不一定是仓库所有者的用户名。Gitee 要求填写，GitHub 可选。仅更改此用户名会保留本地 Git 历史。
- **个人访问令牌（Personal Access Token）**——有权访问该仓库的令牌。使用 GitHub 经典 PAT 访问私有仓库时，需要 `repo` 权限范围。

### WebDAV 与 Nextcloud

1. 在服务器上为一个笔记本创建专用集合（文件夹）。集合必须已经存在；不要把 VNote 指向包含无关数据的共享账户根目录。
2. 选择 **WebDAV**。Nextcloud 也使用此方式，并非单独的同步后端：从 Nextcloud 账户获取 WebDAV 地址，再使用笔记本专用集合的 URL。
3. 填写**集合 URL（Collection URL）**、**用户名（Username）**和**密码或应用密码（Password or app password）**，然后应用配置。

集合 URL 必须是包含主机名和有效路径的 HTTP 或 HTTPS 绝对地址，不能嵌入登录凭据、查询参数或片段。VNote 在这种远端存储普通笔记本文件；空的远端文件夹可能会被保留，而不是递归删除。

!!! warning "优先使用 HTTPS"
    纯 HTTP 会以明文传输凭据和笔记本数据。即使部分笔记正文已加密，也请使用 HTTPS：元数据、独立资源文件和凭据仍需要传输保护。

服务器必须支持安全的条件写入。配置错误可能指出失败的 WebDAV 检查、HTTP 状态，或缺失、弱类型的 ETag（服务器的文件版本标识）。请根据提示检查集合 URL、权限、凭据和服务器兼容性；不要绕过条件写入检查，也不要为了完成配置而盲目覆盖集合。

### 坚果云（WebDAV）

1. 在坚果云中为笔记本创建专用文件夹，并获取**应用密码**。
2. 选择**坚果云（WebDAV）（Jianguoyun (WebDAV)）**，而不是通用 WebDAV。
3. 将**集合 URL**设为 HTTPS 集合地址，例如 `https://dav.jianguoyun.com/dav/vnote-notebook/`。不接受 `/dav/` 账户根目录。
4. 填写**用户名（Username）**和**应用密码（App password）**。使用应用密码，而非账户密码，然后应用配置。

!!! warning "由 VNote 管理的远端存储"
    坚果云存储的是由 VNote 管理的版本，而不是供云端直接编辑的普通笔记本文件。不要在云端修改这些数据，也不要将同一集合用于其他同步方式。远端历史和已删除数据会保留，不会自动清除，因此存储占用可能持续增长。禁用同步不会删除它们。

### 凭据与切换同步方式

同步密码或令牌按笔记本保存在当前设备的操作系统凭据存储中，而不是笔记本设置中。每台设备都需要配置凭据；复制笔记本不会带上已保存的同步密码或 PAT。如果安全凭据存储不可用，请解决该错误，不要把密码写入笔记本 JSON。

可以在**同步信息**中更新凭据。密码或令牌字段不会预填；当对话框提示**留空以保留现有值（Leave blank to keep existing）**时，留空会保留已保存的凭据。更改 WebDAV 或坚果云用户名时，需要重新提供密码或应用密码。

切换同步后端前，先解决冲突并完成待处理的恢复，再使用**禁用同步（Disable Sync）**，然后选择新方式。更改 URL 也需要确认，并会归档或重建本地同步状态。禁用同步会移除当前设备保存的凭据，但保留工作文件和恢复数据，不会移除远端数据。不要混用不同后端的恢复归档，也不要通过删除归档来绕过被阻止的重新配置。

## 从远端打开现有笔记本

使用**打开笔记本 → 远端 URL（Open Notebook → Remote URL）**：

1. 选择发布该笔记本时使用的**同步方式**。
2. 填写远端仓库或集合 URL，以及上文对应的凭据。此处的 Git 登录名字段标为 **Git username**。
3. 在一个已存在的父文件夹下，选择一个**尚不存在**的**本地根文件夹（Local root folder）**。
4. 打开笔记本。Git 会克隆仓库；WebDAV 会下载笔记本文件；坚果云会从 VNote 管理的存储中下载笔记本。

只有服务器允许时，Git 和通用 WebDAV 才能匿名下载。此时将 Git PAT 留空，或将 WebDAV 的用户名和密码同时留空：下载后的笔记本仍可编辑，但添加凭据前同步不会启用。坚果云始终需要用户名和应用密码，不支持匿名下载。

## 边写作边同步

使用笔记本面板的**立即同步（Sync Now）**按钮立刻同步，通过**同步信息（Sync Info）**查看状态或设置。同步进行中可以用同步按钮取消；请等待取消或恢复完成后，再开始其他操作。

你也可以在**设置 → 同步**中启用**自动同步**。**自动同步间隔（Auto-sync interval）**控制后台同步的最短触发周期（设为 `0` / *立即* 则在每次更改时同步）。

## 冲突与恢复

写作前后都进行同步，切换机器时先等待下载完成再编辑。不要在同步尚未完成时，在两台机器上修改同一篇笔记。

对于 Git 和通用 WebDAV，**解决同步冲突（Resolve Sync Conflicts）**提供**保留本地（Keep local）**、**保留远端（Keep remote）**，以及受支持时的**两者都保留（Keep both）**。这些选项选择的是完整版本，也包括删除状态；**两者都保留**会保留普通文件的两个版本，而不会合并正文。元数据和受保护文件需要选择一个完整版本，因此这些条目不能使用**两者都保留**。选择某一版本的笔记本或文件夹索引后，其他保留的文件可能未被纳入索引；请随后检查笔记本的[外部文件](notebooks-folders-notes.md#the-index-and-external-files)。

坚果云冲突按**完整版本**选择，不是逐行合并，也不能独立挑选其中的各个笔记文件。确认前请仔细判断要保留的版本。加密笔记与对应密钥数据必须保持配套，不要将一个版本的密文与另一个版本的密钥拼在一起。

WebDAV 保留恢复日志，坚果云支持继续被中断的操作。如果 VNote 提示恢复尚未完成或同步后端切换被中断，请保留笔记本和恢复归档，遵循错误提示中的恢复指引，并在完成恢复后再修改同步方式、URL 或重新同步。不要把删除日志、密钥文件或恢复备份当成排障捷径。

## 文件夹同步服务

如果不想使用内置同步——或者同步的是原始笔记本——可以改用文件夹同步服务。采用默认文件夹设置时，捆绑笔记本会将笔记、图片、附件、索引和加密密钥保存在**笔记本根文件夹**下。原始笔记本就只是文件夹本身；VNote 把它的元数据和缓存保存在应用数据文件夹中，因此每台机器各自维护对它的记录。

一般模式如下：

1. 把笔记本根文件夹放进由同步工具管理的目录中。
2. 在每台电脑上，把该文件夹**打开**为笔记本（参见[导入与迁移](importing-migrating.md)）。
3. 照常编辑；同步工具会在机器之间传播文件改动。

例如 **Dropbox**、**OneDrive**、**Nextcloud** 和 **Google Drive**。Nextcloud 桌面客户端的文件夹同步是 VNote 内置 WebDAV 的另一种选择；同一个工作笔记本请选择一种同步机制，避免两者同时操作。

!!! tip "编辑前让同步先完成"
    切换机器时，先让同步客户端完成下载，再开始编辑。如果产生冲突副本，请保留它们，直到比对并恢复所需内容。不要手动合并加密文件或密钥元数据；请遵循[加密笔记恢复指引](encrypted-notes.md#backup-and-recovery)。

## 哪些内容会被同步

笔记本根目录中的内容应一起保留，包括捆绑笔记本的索引、配置和完整的加密密钥层级。如果将资源文件或回收站配置在根目录之外，仅复制根文件夹不会包含这些外部路径；备份或迁移时请另行处理。同时妥善保管加密主密码——同步凭据不能代替它。

应用级设置单独保存在 VNote 的[配置文件夹](../customization/settings.md)中，不属于任何笔记本。如果需要的是迁移而非持续同步，请参见[导入与迁移](importing-migrating.md)。
