# 快速访问与历史

随着笔记本不断变大，你每天真正在用的笔记其实是一小撮不断变化的集合。VNote 提供两种快速回到它们的方式：用**快速访问**保留你有意留在手边的笔记，用**历史**回到你最近打开过的笔记。

## 快速访问

快速访问是一个小而固定的笔记列表，用于放置你希望一键即达的笔记——每日日志、持续更新的待办笔记、某个项目的索引页。与历史不同，除非你主动更改，它不会变动。

- 从笔记的右键菜单或快速访问菜单，将其**加入**快速访问。
- 从工具栏或其快捷键**打开快速访问**，直接跳转到某篇固定的笔记。
- 当某篇笔记不再是当下重点时，将其**移除**。

由于快速访问只保存你所选择的内容，它始终是一个简短、信息量高、反映你当前焦点的列表。

## 历史

历史会自动记录你打开的笔记。当你想回到一小时前正在读的东西却又不记得它在哪里时，**历史**停靠部件会按顺序列出你最近打开的笔记。选择任意条目即可重新打开。

历史由系统自动维护——无需你整理。它与[搜索](../search/index.md)和[统一入口](../search/united-entry.md)互为补充：搜索按笔记的内容查找，而历史按你刚才在做什么来查找。

## 何时用哪一个

- 对于反复回看的笔记，使用**快速访问**——固定一次，从此忘掉路径。
- 需要沿着最近的操作回溯到刚接触过的东西时，使用**历史**。
- 当你需要按内容或主题而非近期活动来查找笔记时，使用[搜索](../search/index.md)或[标签](tags.md)。

三者结合，即使在庞大、深度嵌套的笔记本中也能保持快速导航。
