# 快速笔记

**快速笔记**用于*立刻*记下想法，而不必先决定它该放在哪里。一个快捷键即可在预设位置、以预设名称创建笔记，并直接打开等你输入。

## 创建快速笔记

按 `Ctrl+Alt+Q`、使用工具栏的**新建 → 快速笔记**，或双击标签栏的空白区域。VNote 会按照当前**方案**创建笔记并立即打开。

正是方案让这一切变得即时：它预先回答了“放在哪个文件夹？”“叫什么名字？”“用哪个模板？”，因此不会有对话框挡路。

## 快速笔记方案

方案在**设置 → 快速访问 → 快速笔记**中配置。如果你还没有定义任何方案，触发快速笔记会直接带你进入该设置页面。

- **方案（Scheme）**——方案列表，配有**新建**和**删除**按钮。每个方案都是下列字段的一组独立配置。
- **文件夹（Folder）**——笔记创建的位置。留**空**表示使用笔记本浏览器中当前浏览的文件夹，它会随你的工作动态变化。此处支持[片段](../editing/snippets.md)变量，例如 `journal/%yyyy%/%MM%` 会把笔记归入当前的年份与月份，并按需创建这些文件夹。参见[日期与时间占位符](../editing/snippets.md)。
- **笔记名（Note name）**——新笔记的文件名。它同样接受片段变量，默认名称正是借此每次生成不同的文件。
- **模板（Template）**——笔记所基于的[模板](../editing/templates.md)。不设置则创建空白笔记。

## 用法示例

- **日志**：文件夹填 `journal/%yyyy%/%MM%`，笔记名基于日期，再配一个日志模板——一次按键即可打开今天的条目。
- **收件箱**：文件夹留空、名称简单，笔记就会落在你当前工作的位置，之后再归档。
- **会议记录**：固定文件夹加上一个能生成参会人、议程与待办的模板。

快速笔记就是普通笔记：你可以像对待其他笔记一样重命名、移动、打标签和导出。参见[笔记本、文件夹与笔记](../managing-notes/notebooks-folders-notes.md)。
