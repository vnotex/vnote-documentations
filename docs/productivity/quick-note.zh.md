# 快速笔记

**快速笔记**用于*立刻*记下想法，而不必先决定它该放在哪里。选择一个预定义方案，即可按照预设位置、名称和模板创建笔记，直接开始输入。

## 创建快速笔记

按全局快捷键 `Ctrl+Alt+Q`、使用系统托盘菜单的**快速笔记**、选择工具栏的**新建 → 快速笔记**，或双击标签栏的空白区域。在选择器中选定一个**方案**后，VNote 会创建并打开笔记。

即使主窗口已隐藏或最小化，全局快捷键仍可使用，但前提是 VNote 正在运行，且操作系统成功注册了该热键。它使用 `core.shortcuts.NewQuickNote`；与其他应用的冲突或 [Ctrl+Alt 快捷键策略](../customization/settings.md#general-settings)可能使其不可用，此时可以使用托盘或工具栏入口。

## 快速笔记方案

方案在**设置 → 快速访问 → 快速笔记**中配置。没有方案时，VNote 会提示你先进行配置。新建方案默认使用“文档”目录下的 `my_notebook` 文件夹，与首次运行时的笔记本一致；已有方案的文件夹不会改变。

- **方案（Scheme）**——方案列表，配有**新建**和**删除**按钮。每个方案都是下列字段的一组独立配置。
- **文件夹（Folder）**——笔记创建的位置。绝对路径可以指向另一个已打开的笔记本，也可以指向外部文件夹；外部笔记会按实际文件路径打开。留**空**表示使用笔记本浏览器中当前浏览的文件夹，它会随你的工作动态变化。此处支持[片段](../editing/snippets.md)变量，例如 `journal/%yyyy%/%MM%` 会把笔记归入当前的年份与月份，并按需创建这些文件夹。参见[日期与时间占位符](../editing/snippets.md)。
- **笔记名（Note name）**——新笔记的文件名。它同样接受片段变量，默认名称正是借此每次生成不同的文件。
- **模板（Template）**——笔记所基于的[模板](../editing/templates.md)。不设置则创建空白笔记。
- **在分离窗口中打开（Open in detached window）**——每个方案独立设置，默认关闭。启用后，无论从托盘、全局快捷键还是其他快速笔记入口创建，笔记都会在独立窗口中打开。

## 用法示例

- **日志**：文件夹填 `journal/%yyyy%/%MM%`，笔记名基于日期，再配一个日志模板——选择方案即可创建今天的条目。
- **收件箱**：文件夹留空、名称简单，笔记就会落在你当前工作的位置，之后再归档。
- **会议记录**：固定文件夹加上一个能生成参会人、议程与待办的模板。

在笔记本内创建的快速笔记可以与其中其他笔记一样管理。在外部文件夹中创建的笔记则不具备标签等笔记本专属功能。参见[笔记本、文件夹与笔记](../managing-notes/notebooks-folders-notes.md)。
