# 导出

VNote 可将你的笔记导出为便于分享的格式：开箱即用地支持 **Markdown**、**HTML** 和 **PDF**，并可通过 **Pandoc** 或自定义命令导出几乎任何其他格式。

## 通用设置

在导出对话框中，你需要选择范围和目标：

- **范围**——导出当前笔记、当前文件夹中的所有笔记，或当前笔记本中的所有笔记。
- **目标格式**——`Markdown`、`HTML`、`PDF` 或`自定义`。
- **渲染样式**——你可以为导出的输出应用与编辑时不同的样式（样式来自你的[主题](../customization/themes-and-styles.md)）。

## Markdown

将笔记连同其图片和附件一起，导出为单个文件夹中的 `Markdown` 文件。适合生成干净、自包含的副本。

## HTML

将笔记导出为单个 `HTML` 页面，其样式和图片均**内嵌**其中，因此这一个文件便于分享，并可在任何浏览器中打开。

## PDF

直接导出为 `PDF`，或通过 `wkhtmltopdf` 工具导出。使用 `wkhtmltopdf` 时会增加对文档**大纲**（书签）的支持。

**全部合一（All-In-One）**选项会把多篇源笔记合并为单个目标文件——便于把一个文件夹的笔记变成一份文档。

## 自定义

**自定义**目标会运行你指定的命令，最常见的是 [Pandoc](https://pandoc.org/)，用于生成 `docx`、`epub` 等诸多格式。细节请参考 Pandoc 的文档，或接入你自己的脚本。

例如，在 Windows 上这条命令可通过 Pandoc 导出为几乎任何格式——只需把**目标文件后缀**改为 `docx`、`epub` 等：

```
"c:\your\path\to\pandoc.exe" --resource-path=.;%2 --css=%3 --css=%4 -s -o %5 %1
```

在非 Windows 平台上，把路径分隔符从 `;` 改为 `:`。

## 小贴士

- 导出基于**阅读模式**的渲染，因此阅读模式中所见即所得。请先在那里确认数学公式、图表和图片渲染正确——参见[编辑器基础](../editing/editor-basics.md)。
- 若需要带可点击大纲的 `PDF`，请安装 `wkhtmltopdf` 并在对话框中选择它。
- 若需要可重复、可脚本化的转换，一个调用 Pandoc 的[任务](tasks.md)可以作为导出对话框的补充。
