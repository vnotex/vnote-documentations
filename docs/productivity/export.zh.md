# 导出

VNote 可将 Markdown 笔记和思维导图导出为便于分享的格式：开箱即用地支持 **Markdown**、**HTML** 和 **PDF**，并可通过 **Pandoc** 或自定义命令生成其他格式。原生 `.typst` 笔记使用单独的 [PDF 输出流程](../editing/typst.md#pdf-output-and-printing)；通用导出对话框不会保存其编译后的预览。

## 发起导出

你可以从主文件工具栏、Markdown **阅读模式右键菜单 → 导出**，或用 `Ctrl+G, T` 打开导出对话框。右键点击思维导图的空白画布，也能找到**导出**。在 Markdown 阅读模式中，请右键点击普通文档内容而非链接或图片，才能看到导出操作。不属于任何笔记本的文件同样可以导出。

[加密笔记正文](../managing-notes/encrypted-notes.md)无法导出或打印，即使已解锁也不例外。若导出范围包含加密笔记，VNote 会拒绝整次导出，而不是只导出其中一部分。

## 通用设置

在导出对话框中，你需要选择范围和目标：

- **范围**——**当前缓冲区（Current buffer）**使用已打开编辑器中的实时内容，包括未保存的修改；**当前笔记（Current note）**、文件夹和笔记本范围使用磁盘上的已保存文件。若要让这些范围包含最新修改，请先保存。笔记本范围会显示笔记本名称。
- **目标格式**——`Markdown`、`HTML`、`PDF` 或`自定义`。
- **渲染样式 / 语法样式**——分别选择导出页面及代码高亮使用的样式，可与编辑器不同（样式来自你的[主题](../customization/themes-and-styles.md)）。每次会话中首次打开对话框时会选用当前主题的样式，之后保留你的选择。点击紧凑的调色板图标**跟随主题（Follow Theme）**按钮，可再次选用当前主题。

## Markdown

将笔记连同其图片和附件一起，导出为单个文件夹中的 `Markdown` 文件。适合生成干净、自包含的副本。

## HTML

把笔记导出为可在任何浏览器中打开的单个 `HTML` 页面。**完整页面（打包所有资源）**会把页面引用的资源复制到导出文件旁边——若同时勾选**内嵌图片**，则会将其内嵌——从而让页面能够独立渲染。

HTML 使用所选主题的配色，包括表格边框等主题颜色。**添加大纲面板（Add outline panel）**提供可折叠的大纲，支持当前章节高亮及键盘操作。代码块保留**复制**与**折叠/展开**控件；复制已折叠的代码块仍会复制全部代码。启用[标题折叠](../editing/editor-basics.md)时，它也会应用于导出的 HTML。

在导出页面中点击相对 `.md` 链接时，会提供对应的 `.html` 目标，并保留查询字符串或标题片段。接受则打开 HTML 版本，拒绝则保留原始 Markdown 目标。此选择不会创建或检查目标文件：请自行导出被链接的笔记，并保持它们之间的相对目录结构。

## PDF

直接导出为 `PDF`，或通过 `wkhtmltopdf` 工具导出。勾选**使用 wkhtmltopdf（支持大纲）**可获得文档**大纲**（书签）支持；仅对它生效的 **Wkhtmltopdf path** 和 **Wkhtmltopdf arguments** 两个字段在该选项关闭时呈灰色不可用。

`wkhtmltopdf` 的输出如今能正确渲染 CJK 文本与 Mermaid 标签；若无法加载支持 CJK 的字体，对话框会给出警告，而不是悄悄输出方块。Mermaid 图表按打印尺寸以 384 dpi 栅格化，因此打印时依旧清晰。

如果 `wkhtmltopdf` 进程失败，失败信息会显示在对话框的日志面板中，而不是毫无提示地什么也不产出。

**全部合一（All-In-One）**选项会把多篇源笔记合并为单个目标文件——便于把一个文件夹的笔记变成一份文档。

## 思维导图导出

思维导图支持导出为 **Markdown**、**HTML** 和 **PDF**，包括独立树：

- **Markdown** 将主题及其内容转换为可阅读的文档，而非画布图片。同级根节点使用相同级别的标题。
- **HTML** 以自然尺寸展示全宽导图，主题文字可选中，连线使用 SVG。主题链接指向连续排列的文章，其中包含节点备注、图片、图标、标签和链接。
- **PDF** 将导图缩放至第一页，随后在后续页面中排列便于阅读的节点文章。这与只打印画布不同。

选择**当前缓冲区**可包含实时修改；**当前笔记**和批量导出会读取已保存的导图。生成 PDF 前，导出器会等待图片和字体加载；渲染或输出失败会显示在日志面板中。

## 打印

对于 Markdown，**打印**在阅读模式下使用渲染后的文档，在编辑模式下使用当前源码，包括选区和实时预览的分栏布局。若要得到排版后的文档而非源码，请先切换到阅读模式。

对于思维导图，在编辑器工具栏的三点**菜单（Menu）**中选择**打印（Print）**。它会将当前画布布局缩放至一页，包含矢量文字、图片、链接，以及正在编辑的节点文字。若还需要节点文章，请改用 PDF 导出。

## 自定义

**自定义**目标会运行你指定的命令，最常见的是 [Pandoc](https://pandoc.org/)，用于生成 `docx`、`epub` 等诸多格式。细节请参考 Pandoc 的文档，或接入你自己的脚本。

例如，在 Windows 上这条命令可通过 Pandoc 导出为几乎任何格式——只需把**目标文件后缀**改为 `docx`、`epub` 等：

```
"c:\your\path\to\pandoc.exe" --resource-path=.;%2 --css=%3 --css=%4 -s -o %5 %1
```

在非 Windows 平台上，把路径分隔符从 `;` 改为 `:`。

## 小贴士

- Markdown 的 HTML/PDF 导出使用**阅读模式**的渲染。请先在那里确认数学公式、图表和图片渲染正确——参见[编辑器基础](../editing/editor-basics.md)。Markdown 中的 Typst 数学公式和 `typst` 围栏块也受支持，但这与导出原生 `.typst` 笔记不同。
- 若需要带可点击大纲的 `PDF`，请安装 `wkhtmltopdf` 并在对话框中选择它。
- 若需要可重复、可脚本化的转换，一个调用 Pandoc 的[任务](tasks.md)可以作为导出对话框的补充。
