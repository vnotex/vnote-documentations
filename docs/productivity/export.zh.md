# 导出

VNote 可将 Markdown、思维导图和原生 Typst 笔记导出为便于分享的格式。自 [VNote 4.13](https://github.com/vnotex/vnote/releases/tag/v4.13.0) 起，导出目标和选项随所选源类型变化，包括原生 Typst HTML/PDF 及原生源文件副本。**自定义（Custom）**命令（例如 **Pandoc**）可提供其他格式。

## 发起导出 { #starting-an-export }

你可以从主文件工具栏、Markdown **阅读模式右键菜单 → 导出**，或用 `Ctrl+G, T` 打开导出对话框。右键点击思维导图的空白画布，也能找到**导出**。在 Markdown 阅读模式中，请右键点击普通文档内容而非链接或图片，才能看到导出操作。不属于任何笔记本的文件同样可以导出。

[加密笔记正文](../managing-notes/encrypted-notes.md)无法导出或打印，即使已解锁也不例外。若导出范围包含加密笔记，VNote 会拒绝整次导出，而不是只导出其中一部分。

## 通用设置 { #general-settings }

在导出对话框中，你需要选择范围和目标：

- **范围**——**当前缓冲区（Current buffer）**使用已打开编辑器中的实时内容，包括未保存的修改；**当前笔记（Current note）**、文件夹和笔记本范围使用磁盘上的已保存文件。若要让这些范围包含最新修改，请先保存。未启用 **HTML 输入（HTML input）**的**自定义**导出是例外：它始终把磁盘原始文件传给命令。笔记本范围会显示笔记本名称。
- **目标格式**——仅提供所选全部源类型共同支持的目标，见下表。不兼容的选择会在创建输出前被拒绝。
- **渲染样式 / 语法样式**——分别选择导出页面及代码高亮使用的样式，可与编辑器不同（样式来自你的[主题](../customization/themes-and-styles.md)）。每次会话中首次打开对话框时会选用当前主题的样式，之后保留你的选择。点击紧凑的调色板图标**跟随主题（Follow Theme）**按钮，可再次选用当前主题。

| 源类型 | 可用目标 |
| --- | --- |
| Markdown 或纯文本 | Markdown、HTML、PDF、自定义 |
| 思维导图 | MindMap（`.mmm` 源文件）、Markdown、HTML、PDF、自定义 |
| Typst | Typst（`.typst` 源文件）、HTML、PDF、自定义 |

因此，混合选择 Markdown/Typst 时提供 HTML、PDF 和自定义，不提供 Markdown 或 Typst 源文件输出。不支持的选项会隐藏；混合选择中，可见选项可能仅对兼容的源类型生效。

## 源文件副本 { #source-copies }

选择 **Typst** 或 **MindMap** 可保留原生源码，而不是转换成 Markdown。内部相对路径图片会连同其目录结构一起复制。绝对路径、远程资源及越出源目录的路径不会被打包。Typst 导入文件和动态图片引用同样不会被打包；请检查导出日志，并自行提供所需依赖。勾选**导出附件（Export attachments）**可另外复制笔记的附件文件夹；源文件导出不是通用的项目打包器。

## Markdown

将 Markdown 源码及其引用的图片导出到单个文件夹；勾选**导出附件**可包含附件文件夹。对于思维导图，此目标会把主题与节点内容转换为可阅读的 Markdown 文档。原生 Typst 不提供此目标。

## HTML

导出为可在浏览器中阅读的 `HTML` 页面。以下页面打包与阅读控件适用于 Markdown/文本；原生 Typst 和思维导图使用各自的 HTML 渲染器，不提供这些控件。**完整页面（打包所有资源）**会把页面引用的资源复制到导出文件旁边——若同时勾选**内嵌图片**，则会将其内嵌——从而让页面能够独立渲染。

HTML 使用所选主题的配色，包括表格边框等主题颜色。**添加大纲面板（Add outline panel）**提供可折叠的大纲，支持当前章节高亮及键盘操作。代码块保留**复制**与**折叠/展开**控件；复制已折叠的代码块仍会复制全部代码。启用[标题折叠](../editing/editor-basics.md)时，它也会应用于导出的 HTML。

在导出页面中点击相对 `.md` 链接时，会提供对应的 `.html` 目标，并保留查询字符串或标题片段。接受则打开 HTML 版本，拒绝则保留原始 Markdown 目标。此选择不会创建或检查目标文件：请自行导出被链接的笔记，并保持它们之间的相对目录结构。

## PDF

**Typst** 使用内置的原生编译器，保留作者指定的页面布局。它不使用网页渲染/语法样式、基于 HTML 的 PDF 页面布局控件、`wkhtmltopdf` 或 PDF **全部合一（All-in-one）**。参见 [Typst PDF 输出](../editing/typst.md#pdf-output-and-printing)。

**Markdown、文本和思维导图**可直接导出为 `PDF`，或通过 `wkhtmltopdf` 工具导出。勾选**使用 wkhtmltopdf（支持大纲）**可获得文档**大纲**（书签）支持；仅对它生效的 **Wkhtmltopdf path** 和 **Wkhtmltopdf arguments** 两个字段在该选项关闭时呈灰色不可用。

`wkhtmltopdf` 的输出如今能正确渲染 CJK 文本与 Mermaid 标签；若无法加载支持 CJK 的字体，对话框会给出警告，而不是悄悄输出方块。Mermaid 图表按打印尺寸以 384 dpi 栅格化，因此打印时依旧清晰。

如果 `wkhtmltopdf` 进程失败，失败信息会显示在对话框的日志面板中，而不是毫无提示地什么也不产出。

**全部合一（All-in-one）**仅在批量 PDF 导出、全部源均使用基于 HTML 的 PDF 且启用**使用 wkhtmltopdf**时可用。包含 Typst 的选择不能使用此项。额外的**添加目录（Add table of contents）**选项适用于 Markdown，不适用于原生 Typst 或思维导图输出。

## 思维导图导出 { #mind-map-exports }

思维导图支持原生 **MindMap** 源文件副本，以及 **Markdown**、**HTML** 和 **PDF** 输出，包括独立树：

- **Markdown** 将主题及其内容转换为可阅读的文档，而非画布图片。同级根节点使用相同级别的标题。
- **HTML** 以自然尺寸展示全宽导图，主题文字可选中，连线使用 SVG。主题链接指向连续排列的文章，其中包含节点备注、图片、图标、标签和链接。
- **PDF** 将导图缩放至第一页，随后在后续页面中排列便于阅读的节点文章。这与只打印画布不同。

选择**当前缓冲区**可包含实时修改；**当前笔记**和批量导出会读取已保存的导图。生成 PDF 前，导出器会等待图片和字体加载；渲染或输出失败会显示在日志面板中。

## 打印 { #printing }

对于 Markdown，**打印**在阅读模式下使用渲染后的文档，在编辑模式下使用当前源码，包括选区和实时预览的分栏布局。若要得到排版后的文档而非源码，请先切换到阅读模式。

对于思维导图，在编辑器工具栏的三点**菜单（Menu）**中选择**打印（Print）**。它会将当前画布布局缩放至一页，包含矢量文字、图片、链接，以及正在编辑的节点文字。若还需要节点文章，请改用 PDF 导出。

对于 Typst，请导出原生 PDF，再用 PDF 应用打开，以打印排版后的页面。

## 自定义 { #custom }

**自定义**目标会运行你指定的命令，最常见的是 [Pandoc](https://pandoc.org/)，用于生成 `docx`、`epub` 等诸多格式。细节请参考 Pandoc 的文档，或接入你自己的脚本。

**HTML 输入（HTML input）**会在执行命令前渲染所选内容，因此**当前缓冲区**可包含未保存的快照。关闭 HTML 输入时，即使选择当前缓冲区，命令也会收到磁盘上的原始源文件：请先保存，并确保外部工具理解该源格式。此区别同样适用于 Typst 和思维导图文件。批量自定义导出可以使用自己的**全部合一（All-in-one）**选项；它与 PDF 后端的限制不同。

例如，在 Windows 上这条命令可通过 Pandoc 导出为几乎任何格式——只需把**目标文件后缀**改为 `docx`、`epub` 等：

```
"c:\your\path\to\pandoc.exe" --resource-path=.;%2 --css=%3 --css=%4 -s -o %5 %1
```

在非 Windows 平台上，把路径分隔符从 `;` 改为 `:`。

## 自定义导出样式 { #custom-export-styles }

在 HTML 选项中使用**应用自定义样式（Apply custom styles）**及其**编辑（Edit）**按钮，可编辑用户配置文件夹下共享的 `web/css/export.css`。导出前请先保存该文件。此样式表在升级时保留，用于 HTML 以及 PDF/自定义转换的 HTML 输入，不影响原生 Typst PDF 或使用原始源文件的自定义命令。它独立于每个主题的渲染与语法样式。参见[主题与样式](../customization/themes-and-styles.md#applying-export-styles)。

## 小贴士 { #tips }

- Markdown 的 HTML/PDF 导出使用**阅读模式**的渲染。请先在那里确认数学公式、图表和图片渲染正确——参见[编辑器基础](../editing/editor-basics.md)。Markdown 中的 Typst 数学公式和 `typst` 围栏块也受支持，但这与导出原生 `.typst` 笔记不同。
- 若需要带可点击大纲的、基于 HTML 的 `PDF`，请安装 `wkhtmltopdf` 并在对话框中选择它。
- 若需要可重复、可脚本化的转换，一个调用 Pandoc 的[任务](tasks.md)可以作为导出对话框的补充。
