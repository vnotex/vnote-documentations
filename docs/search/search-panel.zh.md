# 搜索面板

**搜索**停靠部件是 VNote 完整的搜索界面。相比之下，[统一入口](united-entry.md)是一个快速、命令驱动的跳转框，而搜索面板则提供了一整套选项，用于按名称或内容在你的笔记本中查找笔记。

## 打开搜索

从导航栏或其快捷键打开**搜索**停靠部件。输入查询词，选择范围和目标，然后执行搜索；匹配结果会列在内容区下方的**位置列表**中，选择其一即可打开对应笔记。

![搜索停靠部件与位置列表中的结果](../assets/screenshots/search.webp){ .screenshot loading=lazy }

## 你能搜索什么

搜索有两个维度：**匹配什么**以及**在哪里查找**。

匹配对象：

- **内容**——笔记内部的文本（全文搜索）。
- **名称**——文件夹和文件的名称。
- **标签**——携带某个[标签](../managing-notes/tags.md)的笔记。

查找范围：

- **所有笔记本**——你在 VNote 中打开的一切。
- **当前笔记本**——你正在使用的笔记本。
- **当前文件夹**——所选文件夹，以及在适用时其子文件夹。
- **缓冲区**——当前在标签页中打开的笔记。

将这些组合起来，你就能从宽泛的「在任何地方找到这个短语」精确到「在这个文件夹里找到这个名称」。

文件模式留空时，内容搜索包含标记为可搜索的文件类型：默认包括 **Markdown**、**文本**（含受支持的源代码和配置文件后缀）以及**思维导图**，不包括 **PDF** 和**其他**。显式填写文件模式会覆盖此类型筛选（`*` 或 `*.*` 请求所有类型），但不会把二进制格式转换为可搜索的渲染文本。参见[文件类型](../managing-notes/file-types.md)。

内容搜索会跳过[加密笔记正文](../managing-notes/encrypted-notes.md)，即使受保护的视图已解锁，也会报告排除了多少篇受保护笔记。文件模式不能绕过此保护。名称、文件夹和标签仍可搜索。

## 搜索选项

面板提供用于优化查询的选项：区分大小写、正则表达式，以及通配符文件模式。当普通关键词返回过多结果时，用它们收紧结果。

## 处理搜索结果

结果列出匹配的笔记（对于内容搜索还会列出匹配的行）。选择某个结果即可在匹配处打开笔记。随后，[大纲](../editing/editor-basics.md)和笔记内查找可帮你精确定位。

## 跨笔记替换

1. 执行**内容**搜索，在**位置列表**中检查匹配行。替换要求结果来自 **Simple** 搜索后端，且搜索已成功完成、结果未被截断。正则搜索也受支持：“Simple” 是后端名称，不表示禁止正则表达式。若结果被截断，请缩小搜索范围或提高结果上限后重新搜索。
2. 输入**替换为（Replace with）**文本，选择**替换选中项（Replace Selected）**处理选中的结果，或选择**全部替换（Replace All）**处理所有已检查的匹配项。选中文件结果会包含其匹配项。替换文本始终**按字面处理**，正则模式也不例外：不会展开捕获组引用或转义序列。留空即删除匹配内容。
3. 在确认框中核对匹配项和文件数量，再选择**替换（Replace）**。修改搜索选项会使替换结果失效，需重新搜索后才能替换。

!!! warning "替换也会保存已有编辑"
    受影响的笔记会被保存，包括替换前已经存在的未保存编辑。此操作**无法跨文件撤销**。若需要恢复整批修改，请事先保留备份或版本控制检查点。

取消会停止批处理，但不会回滚已保存的笔记。点击取消、按 `Escape` 或关闭进度对话框，都会等待正在进行的保存结束后才关闭对话框。请检查完成摘要中的已保存文件与错误。若内容已改动但写入失败，替换后的编辑会保留为未保存状态以便恢复，而不会被旧文本悄悄覆盖；请检查并保存这些笔记。再次替换前需重新搜索。

## 搜索面板与统一入口

- 当你需要选项——范围、匹配类型、正则——以及可浏览的结果列表时，使用**搜索面板**。
- 当你明确知道要找什么，并且更愿意输入一条简短命令直接跳转、不离开键盘时，使用[统一入口](united-entry.md)。

两者使用同一个底层搜索服务。
